# 账号下的人格配置可视化

Web 设置页以账号为单位展示固定人格的部署配置解析结果。一个账号固定一张角色卡，
网页中没有运行时切换角色卡或写入部署配置的入口。

## 账号配置卡片

- 账号号码、人物名称、人格 ID、固定角色卡及其可用性。
- 普通聊天模型与视觉模型分别展示：模型名、服务类型、配置来源、脱敏地址、
  凭据是否配置、请求超时和本地配置状态。
- 聊天模型另展示实际请求的思考强度及配置来源；未指定时标明服务端默认，不推测其他供应商的默认值。
- 记忆库归属、项目相对路径、文件存在性、会话命名空间、共享摘要模型和向量模型。
- 音色 ID、情绪、配置来源、语音开关、服务地址、长度、冷却及尾部噪声清理。
- 参考音色试听，以及百科、表情包、表情意图、记忆检索、压缩、私聊、群聊、
  普通群自动回复、共享场景、天气、图片生成等能力的状态与使用范围。
- SceneHub 演员模型、导演模型、风格样例状态和其他相关参数。

能力逐项区分已启用、未启用、尚未接入、配置不完整和绑定异常。
绑定与聊天配置正常不表示所有能力可用，也不表示已验证外部服务在线。

默认人格普通聊天引用 `AIKE_LLM_*`，接入百科及现有默认人格表情库。
默认人格 DeepSeek 正式聊天读取 `AIKE_LLM_REASONING_EFFORT=low|high|max`，未配置时为 `high`。
普通聊天及默认人格 SceneHub 回复共用该设置，百科工具后续请求继续携带同一强度。
独立人格私聊不继承此项；独立人格 SceneHub 显式 `low` 的例外优先于默认人格配置，并在场景模型中展示。
百科预判保持关闭思考，摘要和表情分类使用各自原有请求参数。部署文件修改后需重启对应进程。
独立人格普通聊天按当前白名单引用 `PERSONA_LLM_*`；百科现已接入公共查询子图，
支持明确查询及自动查词，由 DS 预判公共资料后使用当前角色模型生成一次回复。
设置页展示其预判模型、触发范围和预算。默认人格和独立人格的自动表情现均使用普通聊天和
ChatGraph 共用的成功文本回复后处理，并支持人格 V2 路由。正式库支持角色专属
素材及明确批准的 `shared` 共用素材，冷却与发送频率仍按账号及会话隔离。
20 张新增共用素材已由主人看图确认标签并正式入库，默认人格当前可选 34 张，独立人格可选
20 张；这是本地图库及配置状态，真实模型分类和 QQ 发图仍待重新加载后统一验收。
V2 普通群自动回复的现有实现限制仍明确展示。
表情分类及发送说明见 [默认人格与独立人格自动表情](chat-sticker-reliability.md)。
独立人格 SceneHub 使用默认模型的现有例外保留。
百科执行与配置说明见 [角色百科查询与聊天子图](encyclopedia-chat-graph.md)。
本轮不新增 MainAgent 人格配置；原有项目共用设置仍可展开查看。

## 音色样例

`GET /api/v1/owner-console/settings/accounts/{bot_self_id}/voice-sample`
按当前账号绑定再次校验人格并选择音色，读取本地
`voice-samples/reference/zh/<voice_id>.wav`。

该接口只播放参考音频，不发起语音合成、启动 TTS 服务或发送 QQ 消息。
参考音频可以在语音回复关闭时试听；它不代表已验收情绪、尾部处理和实际合成效果。
文件缺失、损坏或绑定失效时不借用其他角色的音频。

接口要求本地主人设置会话、loopback Host 和专用请求头。文件名和解析后的路径有边界
检查，禁止链接跳转；WAV 类型、大小、时长和完整帧数据有检查。音频及设置响应不缓存。
网页只在用户点击试听后读取音频，切换配置或离开页面时取消请求并释放 Blob URL。

## 数据与维护边界

账号号码是本地主人配置页面中的必要信息，不加入脱敏 CLI 预检报告。
密钥仅展示“是否配置”；不展示角色正文、聊天内容或私人文件绝对路径。
普通聊天与视觉路由共用解析函数，语音入口与配置页面共用音色解析函数。

设置快照不打开数据库，不创建缺失数据库，也不执行完整性检查、污染清理或数据迁移。
每个可维护的账号包含 `memory.maintenance_scope`，供记忆页和诊断页选择固定库。
维护快照携带账号、人格、角色卡、库路径标签、命名空间和配置版本；执行前再次校验。
缺失库会明确报错，不建库、迁移或借用另一个人格的库。MemoryRAG 统计只包含人格记忆文档。
历史污染库清理另行列出具体目标，检查当前引用后处理；本轮没有删除任何记忆库。
真实 QQ、模型、TTS 与场景在线验收按项目整理后的统一验收计划执行。
