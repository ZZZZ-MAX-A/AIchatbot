## 使用方式

前置条件是完成 [账号接入](bilibili-connection-runbook.md)、双方身份绑定，并在专用 Edge 中登录默认人格账号。
默认预览需要该专用浏览器保持运行，可最小化；无需重启 QQ Bot。
`inspect/diagnose` 与显式 `api` 线路仍需要原连接器凭据，不能用固定会话的成功推定其可用。
以下是项目根目录中的命令；从其他目录启动时，需为 Python 和脚本都填写本机绝对路径。

```powershell
# 只读诊断：读取候选和详情，不消耗模型 token
.\.venv\Scripts\python.exe scripts\bilibili_browse.py inspect

# 单片来源诊断：替换为实际 BVID；不读 QQ 记忆、不调用模型、不发送私信
.\.venv\Scripts\python.exe scripts\bilibili_browse.py diagnose --bvid <BVID> --page 1

# 一轮预览：默认每来源最多6条、去重后最多12条、最多精选2条
.\.venv\Scripts\python.exe scripts\bilibili_browse.py preview

# 更小的运行规模：每来源最多3条、最多精选1条
.\.venv\Scripts\python.exe scripts\bilibili_browse.py preview --per-source 3 --max-selected 1

# 实际提交首条合格视频给主人；最多一条，无合格项则不发送
.\.venv\Scripts\python.exe scripts\bilibili_browse.py preview --per-source 3 --max-selected 2 --send-one
```

每次运行结束，终端只打印来源状态、数量、模型用量及结果路径，不打印真实 UID、Cookie、角色卡或个性化选择正文。
报告默认保存在 `%LOCALAPPDATA%\AIchatbot\bilibili\previews`，包含同名 `.md` 和 `.json`。
Markdown 供本机阅读，JSON 保存完整候选、选择决定、字幕证据、覆盖范围、草稿和供应商返回用量。
这些报告包含个人推荐、角色选择和公开字幕内容，留在仓库外，不加入 Git。
报告还记录 QQ 记忆注入状态、数量与长度，不复制原始记忆包。
`AIKE_BILIBILI_HOME` 可以指定其他仓库外私人目录，沿用账号连接器的设置。

## 脱敏诊断日志

`inspect`、`preview`、`diagnose` 自动生成独立 trace，日志在
`%LOCALAPPDATA%\AIchatbot\bilibili\logs\browse-<UTC日期>-<trace>.jsonl`。
单个文件最多 512 KiB，新建时保留最近 20 份本模块日志，不清理其他文件；终端显示路径和日志写入失败次数。
日志不可写时保留原请求错误，额外显示写入失败；`diagnose` 此时返回非零退出码。

记录内容采用白名单：阶段代号、UTC 时间、HTTP/JSON 业务码、耗时、响应类型/字节数/指纹、
本机时间与响应 Date 的差值、参数名称、签名参数编码一致性、账号匹配布尔值、
字幕身份/时间轴校验结果、模型一致性结论和分享否决布尔值。
非 200 正文最多读取 64 KiB，只提取预声明的拒绝/验证信号和指纹；截断时指纹只代表读取前缀。
不记录 Cookie、签名值、签名键、UID、完整 URL、响应正文/自由文本错误、角色卡或 QQ 记忆。
日志保留响应分类与证据指纹，原始字幕仍按既有本地预览策略保存，不额外复制。

`diagnose` 只检查绑定账号、指定视频详情和一个分 P 的字幕来源，HTTP 请求无自动重试，
正常最多 4 次 API GET 加 1 次独立 CDN GET；不运行候选筛选或内容总结。
输出 `source_error` 表示来源失败，`unavailable` 表示没有可用字幕；`ok` 仅表示字幕来源检查通过，
并不表示已核对画面或完成主题一致性/内容理解验收。

2026-10-22 真实诊断：账号与绑定匹配；nav/详情均 HTTP 200、code=0；
WBI player 为 HTTP 412 的 HTML，命中“请求被拒绝”“风控”；本机时间与响应 Date 相差约 0.3 秒，
未检测到系统/环境的显式代理配置，请求参数编码与本地签名输入编码一致。
这些结果尚不能证明服务端验签通过，或排除透明代理、设备状态、出口等其他因素。
该次历史诊断为 0 字幕、0 模型请求、0 私信，相关 72 项离线测试通过；不代表最新固定浏览器线路的状态。

`ok` 表示本轮处理成功，允许没有合适的精选；`partial` 表示部分来源或详情失败，其他结果仍保存；
`error` 表示全部来源失败、所有详情失败、筛选失败或某条总结失败。CLI 在 `error` 时返回 1。
模型网络失败不自动重试，失败请求仍计入尝试次数；供应商未返回用量时标记未知，不能当作零费用。

## 数据流程

1. 默认先检查固定浏览器登录账号与已绑定默认人格 UID 一致；接口对照才读取旧凭据。
2. 分别读取首页推荐与关注动态各一页，提取普通视频，过滤已识别的广告与非视频条目。
   每来源数量为 1–8；按 BVID 去重，保留双方来源。一个来源失败不影响读取另一个。
3. 逐条读取视频详情：标题、简介、UP 主、分区、时长及全部分 P 元数据。
4. 使用固定绑定的默认人格角色卡、同一主人 QQ 私聊记忆及现有默认人格文字模型配置进行初筛。
   每个可读取详情的候选均记录选择或略过的理由；可以全部不选，最多选择两条。
5. 默认在固定浏览器打开精选视频并捕获网页原生 WBI player，核对网页、候选详情和 player 的视频与分 P 身份；
   原接口对照才由 Python 签名。每条最多尝试前两个分 P，总字幕预算 12000 字符。
   优先中文字幕，其次其他语言；记录语言、自动字幕标志、读取失败、截断与未读分 P。
   下载字幕只接受指定 HTTPS CDN 域名，不携带账号 Cookie，不跟随重定向，每响应最多 2 MiB。
6. 字幕身份与时间轴通过校验才请求内容总结。模型先返回字幕主题与视频元数据的一致性判断；
   不一致或不确定时必须返回空摘要，不生成草稿。正常结果返回 1–3 条摘要、分享理由及是否值得分享的判断；
   每条摘要需附字幕段 ID 与确实存在的连续原文引用。引用不匹配或结构无效则不生成分享草稿。
7. 只有一致性判断通过且值得分享时，才拼接角色自然分享话语与规范视频链接，限制为 300 字符，保存本地供检查。
   私信不添加“想分享给你：”标签，不额外拼接总结、字幕依据或审核说明；原始总结、覆盖范围和引用仍供本机核查。
   `not_recommended` 保留判断但无草稿；`source_error`、`source_mismatch`、`source_uncertain` 为错误状态，禁止生成草稿。
8. 指定 `--send-one` 后重新核对身份、引用、分享资格和草稿一致性，再向绑定主人提交首条合格结果。
   以双方账号与 BVID 稳定去重，结果未知或失败不自动重试；平台接受与主人确认送达分别记录。

接口分别为 `/x/web-interface/wbi/index/top/feed/rcmd`、
`/x/polymer/web-dynamic/v1/feed/all`、`/x/web-interface/view`、`/x/player/wbi/v2`。
默认 player 的签名由网页生成；接口对照的签名键从 nav 即时取得并仅在内存缓存，签名和字幕下载 URL 不写入报告。
原接口 player 曾实测 HTTP 412；固定浏览器 player 已在本轮通过，不使用旧接口假成功的字幕代替。
这些接口不是稳定开放平台合同，未来可能要求新参数、签名或验证；失败会记录并停止对应步骤。
视频发现和字幕处理为本项目独立实现，没有复用参考插件的视频浏览线路。

模型使用现有默认人格线路，不新增一份 API Key 配置，也不更改 QQ 聊天的模型或参数。
本预览的结构化任务在 DeepSeek 线路上单独关闭思考，以限定输出预算；普通 QQ 聊天仍使用原参数。

目前按固定跨平台映射使用 QQ 共用只读记忆入口，遵循 QQ 配置的近期原文、正式摘要、现有当前场状态卡与手动长期记忆。
语义召回复用 QQ 的 provider、相似度门槛与 top-k/字符限额；不再使用独立 80/40 候选池、关键词排序或 4000 字符总帽。
读取量与输入 token 可能高于旧版；上下文与角色卡分别提供，不修改角色卡。详细数量和失败状态见 [记忆说明](bilibili-memory-runbook.md)。
筛选理由不得编造主人聊过的兴趣；没有读取到的背景不能声称记得。
独立入口不会执行聊天插件初始化；使用单独的只读数据库连接，不迁移或写回 QQ 记忆。

## 内容依据与边界

`metadata_only` 表示无可用字幕或字幕读取失败，仅有标题与简介，本轮不会为它生成内容总结或可发送草稿。
报告保留选择理由，方便判断后续是否值得增加语音转写。

字幕总结不代表看过画面或完成了完整视听观看，不会提交播放心跳或观看历史。
`partial` 标记未读分 P、字幕截断或失败；即使字幕读取未截断，字幕也可能省略无对白画面。
报告逐分 P 展示最后一条字幕时间与分 P 时长，不把末尾时间等同于完整画面覆盖率。
自动字幕可能识别错误，字幕中的知识或观点也未做独立事实核查。
引用校验只证明原句存在，无法自动保证模型每句话的语义推论正确，需结合本地预览检查。
字幕轨在截断前检查全部条目的有限时间、先后顺序和分 P 时长上界，记录正文指纹用于复核。
接口身份核对及模型主题判断均不能证明所有细节绝对正确；没有画面验收时仍明确只依据字幕。
视频标题、简介和字幕均作为不可信数据传给模型，不开放工具或执行其中命令。

当前没有后台常驻、定时任务、私信消息收取或自动轮询分享。
本入口默认不发送，只有 `--send-one` 才提交至多一条；浏览器私信域名初始化只读取未读数量，不读取会话正文。
本阶段也没有点赞、投币、收藏、关注变更或播放记录上报。
