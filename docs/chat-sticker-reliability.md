# 默认人格与独立人格自动表情：触发、分类和发送诊断

2026-10-13 已完成本地修复与回归，真实模型及 QQ 图片送达留到统一在线验收。源代码需要重新加载 Bot 后生效。

## 业务入口

普通聊天与 ChatGraph 的文本回复使用同一个回复后处理入口。正文至少成功发送一条气泡，回复具备有效互动资格，且对话没有被新消息替代，才调度表情。视觉失败、模型失败兜底、语义语音回复和零条气泡送出均不调度。

支持默认人格和独立人格的主人私聊，按固定账号解析角色和会话。两者使用同一回复后处理入口及独立表情分类服务；人格 V2 路由也保留这项能力。群聊不自动附图。

正式素材的 `persona_key` 可为 `aike`、`linyin` 或 `shared`。前两者只供对应角色使用，`shared` 明确供默认人格与独立人格共用；不会将另一个人格的专属素材自动当作共用素材。`shared` 不是可绑定的角色，空角色、未知角色和绑定异常仍拒绝选图。素材文件与正式索引只保存一份，分类组合和选图共用同一受众过滤函数；冷却、消息间隔、小时计数、轮换袋和异步任务仍按实际账号及会话隔离。

## 现有配置

继续使用 `ENABLE_LOCAL_STICKERS`、`ENABLE_REMOTE_STICKER_CLASSIFIER`、`ENABLE_CHAT_STICKER_ATTACHMENTS` 与独立的 `STICKER_CLASSIFIER_*` 配置。本轮没有改实际 `.env` 或增加需要填写的变量。

`ENABLE_CHAT_STICKER_INTENT_SHADOW` 是原内联意图观察功能，不负责当前自动发图；它关闭不妨碍独立分类器发送。独立分类器开启、附图关闭时仍可观察选图结果。

现有频率和置信度配置继续生效：默认冷却 120 秒、消息进度增加至少 4、每小时最多 6 张、每轮最多 1 张、最低置信度 0.82。消息进度包含用户和助手的已保存消息及已压缩消息数量，不等同于主人发言轮数。只有发送成功才正常消耗频率；图片发送确认超时时结果不明，保守计入频率且不重试。

## 与正式素材库对齐

每次分类前加载并校验正式表情库，只提取当前角色已批准且启用素材的“情绪／强度／场景”组合。组合以系统规则传给分类器，不含素材 ID、文件名、路径、哈希、描述或私人内容。当前消息和已生成的回复继续作为独立 JSON 数据输入。

分类器必须选择实际可用组合；若返回不在可用集合中的组合，记录 `unsupported_combination` 并拒绝发图。选图仍执行精确匹配、人格范围、素材校验、置信度及频率限制。不将 soft 自动替换成 medium 或 strong，也不为提高频率随意发图；没有贴合情绪的素材应判断为不发。

## 分类协议与安全诊断

接受规范 JSON，以及整段仅由一层完整 JSON 代码围栏包裹的内容；可清除开头 BOM 和外围空白。围栏外的解释文字、多个 JSON 对象、重复字段、额外字段、非法枚举、非有限数字、错误类型或置信度越界仍拒绝。不会从任意正文中猜测、截取 JSON。

返回字段仍严格为 `attach`、`mood`、`intensity`、`scene`、`confidence`。`attach=false` 要求三个标签为 null。2026-10-14 按主人要求，输出预算由 180 提高到 `max_tokens=500`，默认人格和独立人格共用该分类请求；保留供应商默认思考模式、提示词及发送规则。该额度在思考开启时也会被思考 token 消耗，不能视为 500 token 的分类正文保证。分类请求额外受到整个请求超时限制，并在完成、出错或取消时显式关闭客户端。

`/表情意图状态` 按当前账号和会话显示最新结果，增加响应字符数、白名单完成原因、有限解析原因以及是否处理代码围栏。状态保存在进程内，重启清空，不显示原始模型返回或聊天内容。

2026-10-14 补充分类用量诊断：每轮保留实际请求的 `max_tokens`、超时预算、分类请求耗时，
以及 API 返回的输入/输出/总 token、`completion_tokens_details.reasoning_tokens` 和
`reasoning_content` 字符数。输出 token 可能包含思考 token，二者不重复相加；思考字符数不是 token 数。
成功、截断、过滤、空响应、解析失败都保留计数。超时或接口错误仅保留请求参数和耗时，不编造用量。
缺失计数显示“未提供”，返回 0 才显示 0；调用前跳过或仍在处理中显示“未调用分类模型或尚无结果”。
思考设置显示“未显式指定（服务端默认）”，仅说明请求设置，不用缺失的 usage 推测是否思考。
非法类型、负数、非有限或超范围计数不展示。诊断仅保存计数，不保存输入、分类正文、思考正文、密钥或接口地址；
沿用现有按账号/会话隔离的进程内状态，不新增日志文件或维护入口。重载后才产生新字段，旧轮用量无法追溯。

## 会话任务与恢复

不同账号和会话拥有各自的分类任务、状态及发送锁，互不阻塞。同一会话的新轮次会取消旧分类；若用户新消息已到达但新回复尚未完成，气泡代次检查也会丢弃旧结果。素材复核后、真正调用发送接口前再次检查有效性。

已经开始的发送无法保证撤回，因此保留当前发送与频率记录的完成过程，下一条选图等待该过程结束。发送接口确认最多等待 30 秒；超时结果标为未知，不重试，并按当前冷却时间暂时暂停该会话。已经确认发图但选图状态提交出错时，也保留发图频率记录，仅暂停当前会话一个冷却周期，期满自动恢复。素材复核仍使用原有的文件与哈希校验。
